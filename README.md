# АвтоСнаб — бот поставщика

Исходники бота поставщика и связанного backend.

- `backend/autosnab_bots/` — бот из интеграционной рабочей копии.
- `backend/` — связанный backend, настройки-примеры и проверки.
- `historical-local-bot/` — прежний локальный вариант для восстановления изменений.

Снимок на 20.11.2026, не новая публикация на сервере. Варианты сохранены отдельно и не объединены автоматически. Токены и `.env` не включены; для запуска требуются собственные настройки и сервисы. Отдельный бот orders-asistant-2 сюда не переносился.
